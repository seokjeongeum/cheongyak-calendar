- 전 주택형 마감·일부 마감·지역 미확인·거주기간 미충족·기타경기·일반 1순위 마감·접수 중 고경쟁률을 시험했습니다. 최신 수집 실패, 미검증, 주택형 결과 누락, 불완전 목록, 조회 후 6시간 경과 시 자동 제외하지 않습니다. 공식 정정으로 접수가 재개되면 복원됩니다.
- 일부 주택형만 마감되면 공고와 모든 가격을 유지하고 마감 배지를 표시합니다. 앞으로 신청할 수 있는 특별공급이 남으면 해당 접수 날짜로 묶으며, 마감된 일반공급 날짜는 달력·후보에서 제외합니다. 숨긴 공고를 다시 표시하면 가격과 제외 근거도 확인할 수 있습니다.
- 유형별 자격 근거에서도 마감된 주택형의 일반공급은 **명확한 불일치**와 공식 마감 원문 근거를 표시합니다. 열려 있는 주택형과 특별공급 결과는 유지합니다. 아직 주택형·공급유형을 선택하지 않은 가능 판정은 마감된 조합이 있으면 추가 확인으로 안내하며, 오래됐거나 실패한 결과와 순위·지역 미확인 상태는 진단을 차단하지 않습니다.
- 첫 API 페이지의 100건이 모두 제외된 경우 두 번째 페이지의 열린 공고를 자동으로 표시합니다. 동일한 판단을 목록·달력 점·표시 건수·거주지 후보에 적용하며, 화면이 켜진 상태에서 6시간이 지나도 제외를 해제합니다.
- 청약순위와 공고별 지역 선택은 브라우저에만 저장됩니다. 통제된 브라우저 시험에서 설정을 바꿀 때 API 요청이 발생하지 않고, 모든 공고·출처 요청은 개인 프로필·지역 선택·소득·자산 없이 공개 GET으로 전송됐습니다.

브라우저 검증은 공식 수집이나 개인 프로필 전송 없이 다음 스크립트로 재현할 수 있습니다.

## 공공임대 제외·앞으로의 접수·자동 갱신 (2026-09-30)

- API의 두 옵션은 기본 `false`이며, 화면은 목록·달력·더 보기 요청에 `exclude_public_rental=true&application_only=true`를 전달합니다. 공공임대·조회 기간 내 접수가 없는 공고를 페이지 분할 전에 제외하고, 민간임대는 보존하는 회귀 시험을 통과했습니다. 중복 공고에서 합쳐진 접수 일정도 검사합니다.
- 진행 중인 공고의 `sort_date`는 조회 시작일로 보정하고 공식 접수 시작·종료일은 유지합니다. 기본 목록은 **현재 접수 중**과 예정 날짜로 표시하고, 선택 날짜의 목록은 해당 날짜로 묶습니다. 종료된 접수 유형은 카드의 일정에서 제외합니다.
- `2026.5.14–2027.3.31` 장기 접수와 종료된 특별공급을 함께 가진 사례에서 **접수 중 · 종료 2027.3.31**과 원문 일정 보존을 확인했습니다.
- 9월 30일 기준 이전 달 버튼은 비활성화, 1~29일은 숫자가 없는 빈칸입니다. 모의 시계로 한국 시간 10월 1일 자정 전환을 시험해 오늘·조회 범위·선택 날짜가 갱신되고 `start > end` 요청이 생기지 않는지 확인했습니다.
- 초기 수집 대기 → 진행 → 완료 뒤 목록·달력이 자동 갱신됐습니다. 최초 목록은 비었지만 최초 수집 상태 응답은 이미 완료인 경합도 복구됐습니다. 당시 대기·진행 30초, 완료 5분 조회와 숨겨진 탭의 조회 중단·탭 복귀 갱신을 확인했습니다. 현재는 위 조건 입력 개선대로 복귀 자체의 조회를 제거했습니다.
- 기관 요청 전에 `running` 상태를 커밋하고 이전 성공 시각·건수를 유지하는 API 시험을 통과했습니다. 인증·권한·만료·한도 오류를 한국어 안내로 구분하고, 상위 오류 내용에 인증키가 포함되더라도 노출하지 않는 시험을 통과했습니다.

## 공개 운영 전 확인할 항목

- 기관이 제공하지 않는 접수일·가격·상한제 값은 추정하지 않습니다. 목록과 공개 문서의 누락 상태를 확인하고 새 공고·정정공고의 원문 대조를 이어갑니다. LH·iH의 API 연결 성공은 모든 공고의 상세 가격·조건을 검증했다는 뜻은 아닙니다.
- 공개 운영 전 iH 운영계정의 심의승인과 각 API 사용 기간·한도를 확인합니다. 현재 로컬 Docker·PostgreSQL 연결과 모바일 화면은 검증했으며 외부 서비스로 배포하지 않았습니다.
- Gemini 추출을 켤 경우 청구가 비활성화된 프로젝트의 키만 설정하고, 무료 한도 초과 시 대기 상태를 확인합니다. 한도 초과 동작과 무과금 가드는 모의 응답 테스트로 검증했습니다.
