## 새 공고와 원문 변경

실행 경로에서 단지명·공고번호·문서 해시·고정 페이지별 검토표를 제거했습니다. 조건은 현재 원문의 신청자격 문단, 수치, 주택형·공급유형 표와 근거에서 추출합니다. 같은 조항에 새 이름·번호·날짜·해시·페이지를 적용하는 회귀 사례를 포함했습니다. 기존 검토표 파일은 과거 테스트에만 남아 있으며 API·수집·재처리·문서 변환의 실행 경로에서 가져오지 않습니다.

지원하는 조건 옆에 낯선 필수 제한이 있거나 자녀 설명의 괄호 안에 추가 제한이 있으면 해당 분기는 원문 검토가 필요한 상태를 유지합니다. 넓은 국내 거주 인용에 자동차가액 한도가 포함됐다는 이유로 그 한도를 검토 완료로 인정하지 않습니다. 이미 비교하는 성년 기준의 조사·띄어쓰기 차이는 같은 조건으로 처리합니다.

지역 판정과 특별공급의 별도 배정은 실제 신청·선정 문단에서 분리합니다. 단지 주소나 과거 공고를 신청지역으로 대신 사용하지 않습니다. 같은 해시의 현재 근거는 유지하고 변경된 문서는 새로 검토합니다. 소득 산정 가족 안내도 현재 공급유형·기준일·해시가 맞는 원문 범위를 사용합니다.

## 보존과 수집

기존 가격·경쟁률·원본·이력을 보존하며 동일 원본 수집은 큰 조건 JSON, 원본 이력과 경쟁률을 반복해서 읽지 않습니다. 같은 날 원문의 구조·신청 조건이 바뀌면 재검토합니다. 원본 공고 저장 완료와 문서 검토 완료는 별도로 기록합니다. 중단된 문서 작업은 체크포인트에서 이어가며, 한 문서의 지연이 다른 출처의 원본 저장을 막지 않습니다. 변환 작업은 별도 프로세스에서 시간·메모리 한도를 적용합니다.

호갱노노는 수집 시 공고·단지 식별자를 대조해 검증한 단지 주소만 제공합니다. 화면에는 검색 링크를 만들지 않습니다. 확인 실패·이름 중복은 확인되지 않은 단지 주소를 생성하지 않습니다.
