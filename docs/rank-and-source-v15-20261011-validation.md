# 순위 부족 사유와 현재 원문 재검토

2026-10-11 후속 수정입니다. 민영 순위 인정기간과 통장 종류가 충족됐다는 표시만 남고 주택형별 예치금 부족이 숨겨지던 화면을 수정했습니다. 같은 순위 결과 옆에서 실제 지역·전용면적별 예치금 요구액, 내 입력, 불일치 또는 과거 잔액 확인 사유를 함께 보여줍니다. 공통 잔액 입력은 한 번만 연결하며 동일 통장 종류 비교를 면적마다 반복하지 않습니다.

공식 모집표·가격에 있는 모든 주택형을 각각 비교해 순위 요건이 전부 충족되면 전체 순위도 충족으로 표시합니다. 큰 주택형의 예치금이 부족하거나 모집표의 주택형 면적이 미확보이면 추가 확인 상태를 유지합니다. 단지명·공고번호·문서 해시별 런타임 분기는 추가하지 않았습니다. 원문 실패가 순위 판정을 막는 경우에는 공고문 발견·다운로드 등 실제 실패 단계와 미확보 자료를 표시합니다.

생애최초의 같은 문서 소유 예외 보존, 불완전한 예치금 표의 처리와 공공 잔여주택 재검토는 [소유 이력 검증](first-home-source-v15-validation.md)과 [공공 잔여주택 검증](public-residual-v15-20261011-validation.md)에 기록했습니다. 서로 다른 기준일의 문서를 거부한 후 계약 일정·지역 조건이 추가되는 오류도 차단했습니다.

최종 API 회귀 780개, 웹 회귀 582개와 모바일 Chromium 검증 31개가 통과했고 프로덕션 빌드가 성공했습니다. 최종 화면 자산은 `index-DkNPXBb1.js`입니다. API 테스트에는 기존 Starlette 사용 경고 1개가 남아 있습니다. 브라우저 검증은 공개 원문 자료와 합성 프로필로 375px 표시, 실제 잔액 입력으로 이동, 입력 저장·포커스 복귀 시 추가 API 요청 없음, 자바스크립트 오류·가로 넘침 없음과 입력 후 다음 화면 반영 22ms를 확인했습니다. 개인 정보와 API 키는 검증 자료에 사용하지 않습니다.

현재 저장된 이전 문서 해석은 수동 `operation=reprocess` 작업으로 갱신할 수 있습니다. 재처리는 예약 수집과 같은 작업 대기열을 사용하며 현재 문서 조건만 변경합니다. 원본·가격·경쟁률과 기존 이력을 유지하고 공개 근거 보고서를 남깁니다. 선운지구다사로움 공식 페이지의 HTTP 503은 원문 검토 완료나 개인 입력 부족으로 바꾸지 않습니다.
