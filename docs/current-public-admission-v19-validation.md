# 최신 무순위·잔여 일반매각 공고 재검토

## 수정 결과

공고의 실제 신청자격에서 ‘수도권 거주’와 ‘금회 입주자모집공고일’, ‘무순위(사후) 주택 입주자모집공고일’을 처리한다. 공급 주소와 최초 공고 날짜로 현재 신청 범위를 추정하지 않는다. 의왕역 한신더휴는 수도권, 에코델타 18·19블록은 부산광역시 조건이며 세 공고의 현재 기준일은 2026-10-12다.

현재 수집 날짜와 이전에 저장된 자격 기준일이 충돌하면 이전 문맥이 새 날짜를 덮어쓰지 않는다. 정정 공고의 별도 게시일은 현재 문서 자체가 게시일과 유지할 자격 기준일을 함께 명시한 경우에만 인정한다. 기존 일반공급 최초 공고일과 계약일 기준은 보존한다. 서류 안내와 함께 적힌 새 부양기간·납세기간 요건도 단순 절차로 누락하지 않는다.

공공 일반매각의 ‘성년자(만19세 이상)’와 글자를 반복해 그린 잔여 오피스텔 제목을 처리한다. 아산의 개인·국내 거주 외국인 대안은 원문 그대로 비교하고 법인 계약 절차는 개인 비교와 구분한다. 전체 66실과 잔여 15실을 구분한다. 구미·대구의 공고일부터 입주까지 자격 유지 조항을 시작일·적용 요건과 함께 표시한다.

같은 게시일·정정 순서의 첨부에서는 PDF를 우선하며 최신 HWP 정정본은 오래된 PDF보다 우선한다. 실제 PDF 데이터는 주소가 HWP/HWPX처럼 보여도 변환하지 않는다. 원주와 아산은 현재 공식 PDF로 검토했으며 성공 후 지난 다운로드·HWP 실패 진단은 대체된다.

전체 공식 검토와 실제 조건이 현재 파서·문서 해시에 연결된 경우에만 같은 해시의 과거 미검증 조건 해석을 대체한다. 부분 검토, 다른 해시, 해시 없는 후보는 유지하며 이전 수정 이력은 보존한다. 에코델타 19블록의 `84A` 가격은 현재 공식 표가 `084.9821A`와의 정확한 대응 및 같은 금액을 증명할 때만 화면에서 중복을 생략한다. 원본 가격 두 행과 가격을 포함한 수정 이력은 유지한다.

구현에는 단지명·공고번호·특정 문서 해시의 예외를 추가하지 않았다. 이름·번호·지역·날짜를 바꾼 사례, 미처리 필수 요건, 충돌하는 날짜, 오래된 해시, 모호한 가격 대응도 회귀 검사한다.
