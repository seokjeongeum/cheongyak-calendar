# 브라우저 주택 소유 판정: 제53조

기준 법령은 [주택공급에 관한 규칙 제53조, 2026년 6월 15일 시행](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joNo=0053&joBrNo=00&lsiSeq=286965&urlMode=lsScJoRltInfoR)입니다. 이전 기준일의 공고는 이 버전으로 자동 확정하지 않습니다. 입력 자료·판정은 브라우저에서만 유지합니다.

## 사실과 판정

보유 주택·분양권·입주권을 주택별 한 행으로 입력합니다. 동일 주택의 지분은 별도 주택으로 중복 입력하지 않습니다. 소유자 관계, 공고 기준일의 취득·처분, 면적, 소재 시도, 법정 가격 산정 방식과 해당 경위를 비교합니다. 보유 예외에 해당한다는 기존 자기판정은 버전 3 이전 시 인정값으로 사용하지 않습니다.

| 호 | 자동 비교하는 사실 | 추가 확인이 필요한 경우 |
| --- | --- | --- |
| 1 | 상속 공유지분, 부적격 통보 후 실제 처분, 3개월 기한 | 통보일·처분일·상속 지분 사실 없음, 아직 미래인 처분일 |
| 2 | 수도권 외 도시지역 밖/면의 단독주택, 거주 후 다른 건설지역 이주, 승인 20년/85㎡/등록기준지 이전 중 한 조건 | 소재지·도시 여부·거주/이주·상속 경위 부족 |
| 3 | 분양 목적 개인주택사업자의 분양 완료 또는 통보 후 3개월 실제 처분 | 미완료 분양, 통보/처분 사실 부족 |
| 4 | 법정 근로자 숙소 건설과 개인사업자 등록 또는 정부시책 근로자 주택 공급 | 일반적인 사업자 등록만 있음 |
| 5 | 세대의 유일한 주택·권리, 전용 20㎡ 이하 | 세대 전체 보유 목록·면적 부족 |
| 6 | 소유자가 본인/배우자의 직계존속이고 기준일 만 60세 이상 | 생년월일·관계 부족; 노부모부양 및 공공임대에는 적용하지 않음 |
| 7 | 폐가·멸실·다른 용도와 통보 후 3개월 내 실제 공부 정리 | 정리 예정일, 통보/완료일 부족 |
| 8 | 종전 건축법 기준 무허가건물과 건축 당시 적법성 증빙 | 적법성 증빙 미확인 |
| 9 | 세대 유일 주택, 법정 종류별 면적·공식 가격 한도 | 시세, 가격 기준일·주택 종류 부족; 공공임대 제외 |
| 10 | 법정 선정 뒤 남은 주택의 선착순 직접 공급으로 취득한 분양권등 | 잔여주택 직접 공급인지 미확인; 전매 매수는 인정하지 않음 |
| 11 | 미반환 임차보증금, 같은 임차주택의 경매/공매 취득, 85㎡와 법정 가격 한도 | 경매·보증금·공식 가격 부족; 공공임대 제외 |
| 12 | 2024년 생애 최초 임차주택 취득, 법정 주택 종류·60㎡·신고가격, 취득 전날까지 1년 거주 | 취득 경위·신고가격·임차 시작일 부족 |

제9호의 아파트는 전용 60㎡ 이하 및 1억원(수도권 1억6천만원), 해당 비아파트·도시형 주택은 85㎡ 이하 및 3억원(수도권 5억원)을 비교합니다. 가격은 별표 1 산정값이며 시세를 대신 사용하지 않습니다. 제11호 가격은 1억5천만원(수도권 3억원), 제12호 거래신고 취득가격은 2억원(수도권 3억원)을 비교합니다.

법정 처분·공부 정리의 완료 여부는 한국 날짜로 확인합니다. 예정 날짜만으로 완료 판정을 내리지 않으며, 기한은 달력 3개월로 계산합니다. 공유지분 전체를 전용면적에 임의로 곱해 축소하지 않습니다. 한 호만 보유해야 하는 조건은 세대의 전체 보유 목록으로 확인합니다.

## 공급유형·순위와 분리

같은 보유 사실도 일반공급과 노부모부양 결과가 달라질 수 있습니다. 공통 무주택 조건도 평가 시 실제 선택한 공급유형을 전달합니다. 현재 주택을 소유하지 않은 것으로 보는 예외는 과거 소유 이력 자체를 삭제하지 않습니다. 생애최초의 별도 소유 이력 조건은 독립적으로 비교합니다.

통장 1순위는 공식 `rank_requirements.complete` 범위의 기간·예치금/납입횟수·통장 종류·추가 요건을 비교합니다. 전체 자격 조건 확보 상태가 부분적이어도 통장 1순위 충족은 표시할 수 있습니다. `ownership_count_max`가 있으면 같은 법정 소유 계산을 사용합니다. 예치금·납입 인정 값은 공식 기준일까지의 값인지 별도로 입력합니다.

신청 지역은 공식 공고 기준일의 거주 범위로 비교합니다. 입력한 시도·시군구·상위 시 전체의 연속 거주 시작일이 해당 기준일 이후이면 현재 주소로 당시의 신청 지역 충족이나 불일치를 확정하지 않고, 해당 기준일의 주소 이력을 확인하도록 표시합니다. 시도나 상위 시 전체 거주가 기준일 이전부터 이어진 경우에는 그 안의 구 전입일만으로 더 넓은 지역 요건을 보류하지 않습니다. 과거 주소 입력란은 없으므로 현재 주소 입력을 과거 주소 확인으로 대신하지 않으며, 이 지역 확인은 민영주택 통장 1순위와 독립적으로 유지합니다.

거주 시작일이 없거나 유효하지 않으면 공식 조건에서 실제로 필요한 시도·상위 시 전체·시군구 날짜를 입력하도록 안내합니다. 지역별 예치금 표도 기준일의 거주 시도를 사용하므로, 시도 전입일이 기준일 이후이면 예치금 지역의 주소 이력 확인을 요청합니다. 고정된 예치금 요구값의 비교와 별도의 신청 지역 불일치가 통장 1순위를 혼동시키지 않습니다.

일반공급의 다른 자격 조건이 아직 정리되지 않은 경우에도 공식 신청 지역의 비교 결과는 표시합니다. 지역 범위가 명확하게 맞지 않으면 불일치로 표시하면서 나머지 공고 조건 확인 사유를 함께 유지합니다. 지역이 맞는다는 결과만으로 전체 공급 자격을 확정하지 않습니다.

## 검증

`web/src/ownership.test.ts`는 모든 12개 경로, 3개월 말일, 완료 전 미래 날짜, 단일 주택 범위, 소유 예외의 공급유형 차이, 공공임대 제외, 공식 가격 기준을 검증합니다. `web/src/qualificationV3.test.ts`는 전체 자격 조건이 일부 부족해도 실제 1순위 확정, 순위 적용 없음, 주택 구분 불명 시 불필요한 질문 억제, 주택형별 예치금, 신청 지역과 장기복무군인 예외를 검증합니다.

예치금의 입력 날짜가 공고 기준일보다 앞서면 그 금액 이상을 계속 유지한 사실도 확인합니다. 금액·날짜를 바꾸면 기존 유지 답변을 재사용하지 않습니다. 예치금 표와 청약부금의 85㎡ 제한에는 근거가 있는 **전용면적**만 사용하며 공급면적을 대입하지 않습니다. 예컨대 동인센트리체의 084.2551A는 공급면적 115.374㎡와 별도로 공식 전용면적 84.2551㎡를 비교합니다.


## v4 가족별 연결

보유 사실의 `ownerMemberId`는 이름 없는 실제 가족 목록의 한 사람에 연결합니다. 본인/배우자는 고정 ID `applicant`/`spouse`이며, 추가 가족은 개별 ID를 사용합니다. 같은 가족 관계인 부모나 자녀가 여러 명이면 예전의 포괄적인 관계 답변으로 소유자를 선택하지 않습니다. v3에서 본인·배우자의 정확한 소유 사실은 연결해 보존하고, 가족 소유 기록·생년월일도 보존하되 새 가족 목록의 사람은 다시 선택해야 합니다.

소유 판정은 제2조로 계산한 공고 기준일 확인 대상만 평가합니다. 형제자매 등 제외 대상자의 보유 기록은 삭제하지 않고 그 세대의 보유 수에서 제외합니다. 본인·배우자 등본에 등재된 해당 가족의 생년월일을 제53조 직계존속 예외에 사용하며, 가족 목록과 소유 항목의 생년월일이 다르면 입력을 확인하도록 표시합니다. 보유 목록 완료 답변만으로 미입력 가족의 미보유를 확정하지 않으며, 각 사람의 보유 사실이나 그 사람에게 연결된 사실 기록이 필요합니다.

가족 관계/등본 위치와 가족 목록 기준일·정확한 과거 공고일 확인이 부족하면 해당 범위를 먼저 질문합니다. 모호한 ‘법정 확인 대상 범위를 확인했나요?’ 질문과 인원 직접 입력은 사용하지 않습니다. 과거 주택 보유도 계산된 실제 가족별 이력으로 비교하며, 오래된 포괄적 가족 자기답변을 새 가족 전원의 확정 이력으로 변환하지 않습니다.
