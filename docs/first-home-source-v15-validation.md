# 생애최초 소유 이력과 부분 문서 검토 · 2026-10-11

생애최초의 실제 신청자격 문단에서 확인한 세대 과거 소유 조건·배우자 혼인 전 취득 및 처분 예외와, 같은 문서의 제53조 직계존속 조항을 다른 통장·해외체류·소득세 문단의 확보 여부와 독립적으로 보존합니다. 금액표나 납세 조항이 미확보이면 전체 분기는 계속 추가 검토 상태이며, 확보한 소유 예외까지 사라지지 않습니다. 공급유형·문서 해시·공식 원문과 실제 페이지를 유지하고 공고번호나 단지 이름으로 분기하지 않습니다.

직계존속의 현재·과거 소유 예외는 기존 [제53조 법령 및 국토교통부 안내 검증](history-and-current-source-v15-validation.md#first-home-ancestor-ownership)의 범위 안에서 비교합니다. 공고일 만 60세·가족 구성·다른 소유자 이력을 비교하며, 같은 문서의 실제 직계존속 조항이 없는 옛 저장 자료에는 예외를 추가하지 않습니다. 해당 자료는 새 일반 파서로 재처리해야 합니다. 필요한 가족 이력이 누락됐을 때는 해당 사람의 입력으로 연결합니다.

이전 파서가 정확한 배우자 혼인 전 소유·처분 예외를 `unparsed` 자식으로 저장한 경우에는 공식 검증·동일 문서 해시·동일 공급 범위가 일치하는 그 조항만 재사용합니다. 다른 문서·공급유형·미검증 문장이나 단순 과거 소유 사실을 예외로 바꾸지 않습니다.

예치금 표는 인쇄된 면적 경계마다 3개 지역 금액을 모두 읽었는지 대조합니다. 예를 들어 85㎡ 이하 행의 금액을 읽지 못한 경우 102㎡ 이하 행을 대신 쓰지 않습니다. 같은 문서의 표 중 하나가 미완성이면 이를 처리 상태에 남겨 전체 검토 완료로 인증하지 않습니다.

검증: 새 공고명·번호·날짜·문서 해시·11쪽 이동, 통장/해외체류/납세 조항 누락, 실제 직계존속 조항 누락, 다른 문단의 배우자 예외 및 예치금 85㎡ 행 누락을 포함한 새 API 회귀 7개와 기존 해당 공고 변조 검증까지 **8개 통과**. 웹 소유 예외·공급유형 제한·신청자격 회귀 **46개 통과**. 공고문과 테스트 자료는 공개 자료이며 개인 입력은 서버로 보내지 않습니다.
