## 표시 기준

## 내 가점과 과거 결과

[주택공급에 관한 규칙](https://law.go.kr/lsInfoP.do?lsId=008243), [청약홈 공식 가점 계산기](https://www.applyhome.co.kr/ap/apg/selectAddpntCalculatorView.do)와 실제 모집공고를 대조합니다. 무주택기간 32점·부양가족 35점·통장 17점을 공고 기준일로 브라우저에서 계산합니다. 생년월일·혼인·소유/처분 이력·은행 인정 가입일을 재사용하고 가점용 가족 인정 사실을 추가로 받습니다.

- 만 30세·혼인·무주택 전환일, 기간/월 경계와 미성년 가입기간 인정 한도를 비교합니다.
- 부양가족은 신청자의 세대주 여부, 직계존속 3년 연속 등재, 직계비속 미혼/나이/등재, 국외 체류와 손자녀 인정 사실을 비교합니다.
- 60세 이상 부모 소유의 무주택 자격 예외를 가점 부양가족 인정에 사용하지 않습니다. 소유 예외를 확인하지 못하면 점수를 확정하지 않습니다.
- 배우자 통장 인정기간 50%·최대 3점을 더하되 통장 항목 합계는 17점으로 제한합니다. 현재 배우자 통장 없음이 과거에도 없었다는 뜻이 되지 않도록 날짜별 사실을 사용합니다.
- 미입력/과거 상태 미확인은 확정 총점으로 합산하지 않습니다. 확인된 항목과 필요한 질문만 표시합니다.

## 자녀·임신 사실

‘계속 자녀·임신 없음’은 명시적인 공통 선택입니다. 기존 현재 없음 입력을 과거 이력 없음으로 자동 변환하지 않습니다. 직접 선택한 뒤에는 독립적인 자녀·임신 사실의 변경 이력 없음으로 저장하고 인정 자녀 수 0명과 다자녀 요건을 비교합니다. 같은 날짜 질문을 공고별로 다시 요구하지 않습니다.

현재 자녀 없음이면 생년월일·입양·추가 버튼을 숨기고, 임신 없음이면 태아 수를 숨깁니다. 실제 자녀/입양/임신 이력은 보존합니다. 저장된 실제 이력이 있으면 ‘계속 없음’으로 덮어쓸 수 없습니다. 변경일 질문과 링크는 자녀·임신 각각의 입력 항목에 연결합니다.
