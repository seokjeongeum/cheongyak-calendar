# 날짜 비우기·공통 순위기산일 검증

처분 완료일과 수동 무주택 시작일에 ‘지우기’를 제공한다. 삭제는 빈 문자열로 저장하며, 항목 자체·취득 이력은 보존한다. 날짜 직접 삭제와 삭제 버튼 모두 같은 저장 경로를 사용한다.

민영·국민주택 순위기산일이 같으면 공통 날짜 하나로 입력한다. 서로 다른 기존 날짜는 보존하고 두 입력을 표시한다. 은행 인정일을 따로 입력하는 설정을 저장하므로 별도 날짜 하나를 삭제해도 다른 날짜로 다시 채우지 않는다. 전환 등으로 실제 은행 인정일이 다른 경우를 동일한 날짜로 가정하지 않는다.

검증 결과:

- 기존 프론트엔드 테스트 **662개 / 56개 파일 통과**, 배포 빌드 통과.
- Chromium 375px·1280px **14개 확인**: 처분일·무주택 시작일 버튼 삭제, 네이티브 날짜 삭제, 닫기 시 저장, 새로고침 시 빈 문자열 복원, 공통 기산일 한 번 입력, 다른 기산일 보존·독립 삭제, 가로 넘침 없음, JavaScript 오류 없음, 개인정보 API 전송 없음.
- 실제 이용자의 입력을 읽지 않고 합성 개인 사실과 격리된 공개 API 응답을 사용했다. 시계는 한국 시간 2026-10-13으로 고정했다.
