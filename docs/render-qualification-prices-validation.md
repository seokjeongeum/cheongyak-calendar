## 화면과 운영 재처리

- 375px·CPU 4배 제한 화면에서 가격과 경쟁률 유지, 회색 공고·달력 집계, 최신 Worker 적용, 브라우저 저장, 개인정보 미전송과 포커스 복귀 조회를 검증했다. 입력·클릭 합산 p95는 78.8~146.4ms, 최신 Worker 응답은 423.5~475.1ms였다. 모바일 100ms 목표는 반복 측정에서 일관되게 충족되지 않았다. 데스크톱 합산 p95는 28.2ms였다.
- 재처리 실행기는 운영 공개 목록과 명시한 공고의 중복 제거 전 원본 UUID를 확보한다. 50건 이하 배치의 처리 단계, 검증 조건 수, 가격 변경 전후는 GitHub Actions의 `public-document-review` 결과에 기록한다.
- 원문을 확보했어도 판독하지 못한 조항은 서비스 검토 부족으로 남긴다. 최초 공고를 준용한다는 문구와 일자는 현재 원문의 페이지에 연결한다. 최초 첨부를 확인한 경우 해당 URL과 해시를 기록한다.

## 운영 결과

11월 12일 KST [전체 원본 재처리](https://github.com/seokjeongeum/cheongyak-calendar/actions/runs/43220240615)와 [창원·A-2 보완 재처리](https://github.com/seokjeongeum/cheongyak-calendar/actions/runs/43221784088)가 완료됐다. 원본 UUID, 확보 조건, 실패 단계, 변경 전후 가격은 각 실행의 `public-document-review`에 저장됐다.

11월 13일 KST 운영 목록의 오늘 이후 접수 공고 54건에서 v20 판독 기록을 확인했다. 가격 614행 중 603행은 공식 근거가 있다. 운영 Chromium 375px 검증 12개를 통과했다. 광교 총액과 납부 구성, 창원 총액과 별도 비용을 화면에서 확인했고, 11월 9일 접수가 끝난 A-2는 상세 API에서 세 가족 경로와 원문 연결을 확인했다.

11월 13일 추가 대조에서 시흥거모 S-1·A-6과 안산신길2 B-1·A-6의 청약홈 페이지에는 첨부가 없었다. 공고번호·기준일·해시가 일치하는 LH PDF를 사용했다. 시흥거모 S-1 정정은 10월 23일 자격 기준일을 적용했다. 정선산수빌은 공식 게시판이 가리키는 직접 파일에서 확보했고, 의정부우정 A-1은 제한 시간 내 재판독을 확인했다. 운영 배치는 대상과 연결 원본 9건에서 검증된 조건 153개를 처리했다.
