## 화면과 운영 재처리

- 375px·CPU 4배 제한 화면에서 가격과 경쟁률 유지, 회색 공고·달력 집계, 최신 Worker 적용, 브라우저 저장, 개인정보 미전송과 포커스 복귀 조회를 검증했다. 입력·클릭 합산 p95는 78.8~146.4ms, 최신 Worker 응답은 423.5~475.1ms였다. 모바일 100ms 목표는 반복 측정에서 일관되게 충족되지 않았다. 데스크톱 합산 p95는 28.2ms였다.
- 재처리 실행기는 운영 공개 목록과 명시한 공고의 중복 제거 전 원본 UUID를 확보한다. 50건 이하 배치의 처리 단계, 검증 조건 수, 가격 변경 전후는 GitHub Actions의 `public-document-review` 결과에 기록한다.
- 원문을 확보했어도 판독하지 못한 조항은 서비스 검토 부족으로 남긴다. 최초 공고를 준용한다는 문구와 일자는 현재 원문의 페이지에 연결한다. 최초 첨부를 확인한 경우 해당 URL과 해시를 기록한다.
