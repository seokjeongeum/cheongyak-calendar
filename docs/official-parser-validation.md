## 비교 가능한 범위

- 거주지역은 해당 시도 전체에 거주하거나 명시된 수도권 시도 묶음에 거주할 수 있다는 문장이 확인될 때만 비교합니다. `경기도 수원시`처럼 시군구로 한정한 문장을 경기도 전체 요건으로 확대하지 않습니다.
- 유형별 자녀 수·나이, 임신·입양 포함 여부, 혼인 7년, 노부모 나이·부양기간·같은 등본, 주택 소유·과거 소유, 소득세 납부 연수 등 확보된 항목을 비교합니다. 혼인기간은 84개월로 반올림하지 않고 정확한 기념일을 사용합니다.
- 무주택·과거 소유·소득세·혼인 등에 공고문 예외가 있으면 예외 원문을 함께 보관합니다. 예외 적용을 구조화하지 못한 경우 기본 조건의 불일치를 최종 탈락으로 확정하지 않습니다.
- 일반·특별공급마다 요구되는 조건의 확보 상태를 별도로 제공합니다. 일반적인 순위 적용 아파트의 전체 요건은 `complete: false`로 유지합니다. 검토한 무순위·재공급 세 공고의 일반공급 신청 요건과 잠실 개인 신청요건은 정확한 문서 해시 검토로 확보합니다. 신청 절차의 중복 접수 금지·신청금 납부 등은 요건과 구분합니다.
- 통장 순위 확보 상태 `rank_requirements.complete`는 전체 자격과 독립적입니다. 동인·A6·광명의 실제 순위 표와 추가 제한을 해시별로 검토했습니다. 검증한 비규제 민영 표도 공식 통장 종류·기간·예치금 세 항목과 비규제 근거가 모두 확보될 때 완전한 순위 요건으로 처리합니다. 기준일 이전 잔액·납입 실적과 전환 인정 사실은 사용자의 브라우저 입력으로 비교합니다.
- `area_sqm`의 공급면적을 예치금 면적 기준으로 사용하지 않습니다. 공식 표의 주택형·주거전용면적 열이 일치하는 행과 API `EXCLUSE_AR`를 `unit_exclusive_areas`에 보존하고 공개 가격의 `exclusive_area_sqm`으로 투영합니다.
- 동인 5쪽은 대구·경북 신청 범위, 대구 우선권, 10년 이상 현재 장기복무 군인의 거주 예외를 제공하며 ‘기타지역’을 전국으로 확대하지 않습니다. 광명의 일반공급 전량 해당지역 순차배정은 `regional_allocation`으로 보존합니다.

## 무순위·재공급 검토

`application_method`는 공식 문서 제목으로 사후접수·임의공급·계약취소 후 재공급·선착순·오피스텔을 구분합니다. API의 잔여세대 묶음만으로 사후접수와 계약취소를 같은 조건으로 처리하지 않습니다. `qualification_context`의 `original_announcement_date`는 최초 사업 공고일, `application_announcement_date`와 `application_criterion_date`는 이번 공고·신청 조건 기준일입니다. 예전 최초 공고일이 이번 거주·나이 조건에 적용되지 않습니다.

세종·신림의 성년 조건은 공고가 적용하는 [제19조제5항](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joNo=0019&joBrNo=00&lsiSeq=286965&urlMode=lsScJoRltInfoR)과 [제26조제5항](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joNo=0026&joBrNo=00&lsiSeq=286965&urlMode=lsScJoRltInfoR)의 2026-06-15 시행본을 대조했습니다. 공고의 적용 문서·해시·페이지와 법령 근거 URL·조항을 따로 보관합니다. 19세 이상 조건이 충족되지 않으면 법률상 성년 예외를 미확인으로 남기며, 강변의 미성년 세대주·자녀 양육/형제자매 부양 예외도 기본 연령 불충족만으로 최종 탈락을 확정하지 않습니다.

해외 연속 90일 요건은 7일 내 동일국가 재출국의 합산과 신청자만 생업 때문에 해외에 있는 제4조제8항 예외를 보존합니다. 과거 당첨·계약·추가입주자 사실은 최초 사업번호별로 비교합니다. 청약 제한은 본인, 본인·배우자, 확인 대상 세대원 범위를 나누며, 소유 주택의 일반적인 전매제한 기간을 청약 불가 사유로 바꾸지 않습니다.

검토한 필수 조건과 제한 항목이 모두 생성되고 원문 URL·해시·기준일·검토 페이지가 일치하는 경우만 유형 확보 상태를 완전으로 표시합니다. 문서가 변경되거나 필수 제한 문구가 매칭되지 않으면 확보한 부분 조건을 보여주되 전체 가능 판정은 보류합니다. 일반 아파트·오피스텔의 v3 검증 조건은 재처리 전까지 유지하며, 구형 무순위 판독과 새로운 검토가 존재하는 중복 공고의 구형 조건은 공개 응답에서 제외합니다. 원본과 이력은 수정하지 않습니다.

정기 API 재수집의 불명확한 주택 구분이나 통장 필요 여부가 같은 파일의 공식 문서 판독을 지우지 않도록 메타데이터를 함께 보존합니다. 이번 무순위 기준일은 문서 근거로 유지하고, 규제지역 같은 API 상태 값은 새 응답으로 갱신합니다. URL·문서 해시가 실제 변경되면 이전 문서의 조건과 메타데이터를 함께 해제합니다. 실제 세 공고의 `문서 처리 → 저장 → API 재수집 → 목록·상세 조회`를 회귀 테스트로 확인합니다.

## 로컬 처리와 재처리

PDF는 페이지 좌표에 따른 읽기 순서, HWPX는 문서 섹션, HWP는 설치된 LibreOffice의 로컬 변환으로 처리합니다. 읽지 못한 문서에도 새 파일 해시는 보관해 기존 문서의 검증 조건을 잘못 이어 붙이지 않습니다. 파일 10MB, PDF 250쪽, 추출 텍스트 150만 자 한도를 적용합니다. 이미지뿐인 문서와 모호한 표는 지원 범위 밖으로 안내합니다.

Gemini 설정·무료 한도와 관계없이 로컬 처리는 실행됩니다. 모델 429는 모델 작업만 지연시킵니다. 날짜별 로컬 확인 기록과 모델 재시도 시각을 분리하여 같은 날 임시 대기 시간이 지난 모델 작업도 다시 확인합니다. 유료 호출은 허용하지 않습니다.

```bash
docker compose run --rm worker python -m app.extract.reprocess --active --limit 50
# 공개 공고 UUID를 지정해 과거 공고도 검토할 수 있습니다.
docker compose run --rm worker python -m app.extract.reprocess --notice-id <공고_UUID>
```

이 명령은 `allow_gemini=false`로 실행되며 개인정보를 받지 않습니다. 네트워크 조회 전에 읽기 트랜잭션을 종료하고, 조회 후 공고별 잠금으로 최신 공고를 다시 읽습니다. 일반적으로 조건·문서 해시를 갱신하며, 잠실처럼 정확한 문서 해시로 검토한 가격은 잘못된 임대 자리표시를 교정합니다. LH 상세 URL의 부모39·세부42는 행복주택으로 분류를 교정합니다. 동시 수집된 일정과 다른 가격은 유지합니다. URL·기준일·주택 종류·해시가 동시에 정정되면 적용을 보류합니다. `official_conditions` 수집 상태는 성공·부분 처리·실패 중 하나로 종료되며 완료된 건수는 보존합니다.

`competition_state.proof_invalidated`는 호환 가능한 열 추가로 저장됩니다. 실제 공고·문서 정정이 발생하면 켜지고, 대기·진행·조회 실패를 거쳐도 유지됩니다. 새 공식 결과를 성공적으로 확인하면 해제됩니다. 과거 공식 경쟁률과 변경 이력은 보존합니다.

`test_official_rules.py`, `test_v3_official.py`, `test_v4_unranked.py`, `test_extract.py`, `test_collectors.py`, `test_reprocess.py`에서 실제 원문, 혼합 조건, 누락 표, 기준일 충돌, 유형별 기간, 원문 위치, 무료 한도, 읽기 실패, 동시 가격·일정 정정, 문서 정정, 추출 상태 동시 생성과 재처리 멱등성을 확인합니다. 무순위 실제 세 사례의 지역·세대주 차이, 최초/이번 공고일, 제한 대상자 범위, 미성년 예외, 해외·외국인 조건과 호환 가능한 v3 유지도 확인합니다.
