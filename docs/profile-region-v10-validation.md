# 가족 사실 재사용과 이번 공고의 지역 조건 검증

2026-10-09 검증. 개인 입력은 브라우저 저장소와 판정 워커에서만 처리하며, 아래 원문 자료는 공개 모집공고입니다.

## 변경된 판정

가족·가점 가족·주택 목록의 완료 여부를 다시 확인하는 질문을 제거했습니다. 실제 가족 관계와 등본 위치, 보유 여부, 소유자별 보유 수와 취득·처분 기록을 비교합니다. 빈 가족 목록은 본인·배우자 외 가족의 존재 여부만 묻습니다. 과거 기록에서 오늘의 완료 선언이나 보유 수를 가져오지 않습니다.

부양 대상은 가족 ID로 연결합니다. 생년월일·등본 위치·연속 등재일·본인 및 배우자 소유 사실을 기존 입력에서 재사용하고, 필요한 날짜는 원래 가족·가점·주택 입력으로 이동합니다. 부모 60세와 공고의 65세 조건처럼 불일치가 확정되면 해당 경로의 추가 질문을 중단합니다.

별표 1의 공식 평가가격, 주택과 권리의 가격 적용일, 민영·국민주택의 은행 인정 순위기산일을 설명했습니다. 소득 산정 인원은 주택 확인 가족·가점 부양가족과 구분하고, 동일 문서 해시와 공급유형에서 검토한 포함 범위·소득 합산 대상을 표시합니다. 공통 API 키가 저장된 서비스의 상태 문구는 모두 `공통 키 연결됨`입니다.

공고의 10년 이상 현재 장기복무군인 거주 예외와 해당지역·기타지역 구분도 원문에 연결했습니다. 산곡의 25년 군인 해당지역 예외에는 국방부(국군복지단) 추천이 추가로 필요합니다. 복무 기간만으로 이 예외를 충족했다고 표시하지 않으며, 추천 사실의 비교 지원 부족을 구체적으로 표시합니다.

한양립스 원문 1쪽은 통합특별시의 동구·서구·남구·북구·광산구가 기존 광주 범위임을 명시합니다. 이 대응표와 현재 문서 해시가 일치할 때만 다섯 구를 해당지역 범위로 사용합니다. 한 구에서 1년 이상 연속 거주하면 기간을 충족하지만, 짧은 현재 구 거주기간만으로 다섯 구 사이의 이전 거주기간까지 불충족이라고 추정하지 않습니다. 해당 이력이 없으면 과거 거주 이력 확인 필요로 남깁니다.

천안 2026000498의 기존 공식 첨부 해시를 다시 대조했습니다. 향남 2026000463은 정확한 공고번호·날짜의 정정 공식 PDF 대체 경로를 추가했습니다. 청약홈의 동일 첨부는 static 호스트 HTTP 실패 시 www 호스트로도 확인하며, 최대 세 번의 문서 후보 시도 안에 검토된 정확한 파일을 확보하도록 했습니다.

이전 다운로드 처리 버전에서 오늘 실패한 문서는 새 버전에서 한 번 재시도합니다. 같은 문서 해시의 지역·신청 조건은 부분 재처리에서도 보존합니다. 파일 변경과 확보 실패는 구분합니다. 원본·가격·경쟁률·변경 이력을 삭제하거나 예시 데이터로 대체하지 않습니다.

익산 2026000402는 [전북개발공사의 2026-10-08 공식 공고](https://www.jbdc.co.kr/notice/notice.do?bbsId=BBSMSTR_000000000011&mode=view&nttId=16011&pageIndex=1)와 공고번호·날짜·제목·기관이 일치할 때 공공임대로 분류합니다. 기존 DB 원본은 유지하며 목록·상세의 공개 표현과 공공임대 제외 필터를 바로잡습니다.

## 검증과 배포

- API 전체 테스트 348개 통과.
- 웹 전체 테스트 458개 통과, TypeScript 검사와 프로덕션 빌드 성공.
- [프로필 브라우저 검증](profile-facts-v10-browser-validation.md): Chromium 375px·1280px 34개 확인, 입력 후 다음 화면 갱신 최대 47ms.
- 실제 공식 문서 추출 결과를 사용하는 추가 375px 지역·공통 키 검증 14개 통과.
- 브라우저에서 가로 넘침·JavaScript 오류·개인 입력 전송·포커스 복귀 조회 없음.

검증은 로컬 코드와 공개 원문 기준입니다. 프로덕션 DB를 수정하거나 관리자 키를 읽지 않았습니다. 공개 Render 앱의 최신 파일을 배포하고 `지금 수집 시작`을 실행해야 실패했던 문서의 원문 해시와 지역 조건이 저장됩니다. 수집 후 `수집 상태 새로고침`에서 처리 결과를 확인합니다. 무료 운영 설정과 기존 기본 브랜치의 예약 수집 활성화 상태를 이번 변경으로 바꾸지 않았습니다.
