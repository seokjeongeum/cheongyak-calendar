# Independent feed completion and resumable document review

The collection that began at 06:45 KST on 2026-10-10 was GitHub run 37995269974. Its metadata records cancellation at 06:50:03, rather than a 60-minute timeout. Before this change, all ready sources nevertheless remained `running` until every PDF had finished, so cancelling a document pass made stored feeds appear failed.

The generic worker now commits and finalizes each ready source's raw notices, prices and schedules before document work. REB's current-receipt batch is also committed before archival model requests. A later archive/model failure reports partial coverage with the missing stage, without invalidating that saved batch. Document progress remains separate from the source's successful feed timestamp and never changes it back to `running`.

`DocumentExtractionState.audited_on` is the durable per-notice checkpoint. Unstarted/cancelled audits remain pending; finished unchanged rows are skipped on restart. Never-attempted and new-parser work precede daily rechecks, while source document turns share one fair semaphore. A timed-out audit preserves prior hash-bound facts and prices, records a sanitized processing diagnostic, and defers that task for three hours so one failing document cannot monopolize each restart. No per-project retry registry is used.

The source fetch/save phase is bounded at ten minutes per provider; the document pass has a shared thirty-minute budget and a 120-second per-item limit; competition has its own twenty-minute pass. Ready feeds continue independently. Pending documents are explicitly reported for the next scheduled run. The existing three-hour schedule, shared collection lease, originals, revisions and competition records are preserved. The worker limits cooperative async work; the pipeline owns isolation/bounds for local PDF/HWP execution.

Validation: 103 local tests passed across worker fairness, collectors, generic document retry and collection ownership. Meaningful regressions cover interruption after raw completion, incomplete archival fetch after a saved current batch, timed-out PDF followed by other sources, durable timeout cooldown, zero document budget followed by restart completion, unchanged archive skip, competition timeout, same-hash corrections and preserved prices/history. All provider HTTP and public complex-link discovery are mocked in these worker tests.
