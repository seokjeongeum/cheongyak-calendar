# 공급표 일반화 검증 — 2026-10-10

`supply_tables.py`는 현재 문서의 공급대상 표에서 공급유형 열, 주택형, 행별 총 공급·특별공급 소계·일반공급, 인쇄된 열별 합계를 읽습니다. 공고명·공고번호·문서 해시·페이지 번호·예상 주택형 목록·예상 물량을 구현에 저장하지 않습니다. 문서의 모든 페이지를 살펴보고 표가 다음 페이지에 이어지는 경우도 처리합니다.

검증된 공급표의 기존 API 셀은 값과 원문 출처를 그대로 유지합니다. 현재 PDF의 합계가 모두 맞고 기존 API의 모든 양수 셀이 표와 일치할 때만 빠진 셀을 PDF 근거로 보완합니다. 0세대 셀과 최하층 우선배정 열은 별도 모집 물량으로 만들지 않습니다. API·문서·중복 API 셀 간 불일치는 `conflict`, 열 순서를 확정할 수 없거나 총계가 누락된 경우는 `partial`로 남깁니다. 여러 회차를 합한 표의 물량을 현재 회차에 배정하지 않습니다.

실제 산곡 2026-10-08 공고의 53개 API 셀(1,163세대)을 현재 문서의 공급표와 대조했습니다. 기존 53개 셀은 그대로 보존하고, API에 없던 신생아 9개 셀(126세대)을 문서 근거로 보완해 양수 셀 62개·1,289세대가 됩니다. 이 수와 문서의 페이지는 회귀 검증의 기대값이며 추출 조건에 들어가지 않습니다.
